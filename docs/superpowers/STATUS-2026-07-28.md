## 🛠 DEVICE / TOOLING GOTCHAS (verbatim — these keep getting rediscovered)
- **Flip 6 `adb screencap` returns BLACK** (Impeller hardware overlay). Working
  capture: `screenrecord --time-limit 2 /sdcard/r.mp4` → pull → extract last
  frame with **opencv** (`cv2.VideoCapture`). `service call SurfaceFlinger 1008
  i32 1` un-blacks screencap on the emulator but NOT the phone.
- Screenshot coords: displayed 818px wide = real 1080px → **multiply by 1.32**.
- **Prefix adb `/sdcard` commands with `MSYS_NO_PATHCONV=1`** (Git Bash mangles
  `/sdcard` → `C:/Program Files/Git/sdcard`).
- USB drops when the phone sleeps → `adb shell svc power stayon usb`. If the
  device vanishes from `adb devices` entirely, it's usually USB mode =
  "Charging only" (needs File-transfer/MTP) or a charge-only cable.
- Tools: adb = `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`;
  gh = `%LOCALAPPDATA%\Programs\gh-cli\bin\gh.exe` (auth manjo00);
  keytool/apksigner via `C:\Program Files\Android\Android Studio\jbr` +
  build-tools `lib/apksigner.jar`.
- Release APK is **debug-signed** (cert SHA-256 `94392f58…f94ee6b3`, CN=Android
  Debug) → `adb install -r` updates in place, no data loss.
- Release ritual: `flutter build apk --release` → `gh release create vX.Y.Z
  --repo manjo00/uplan-releases --title … --notes-file … <apk>` (APK asset
  mandatory, must not be a draft, tag semver > installed) → `adb install -r`.
